## 1. 平台架构

```
┌─────────────────────────────────────────────────┐
│                WordPress 站点                    │
│                                                 │
│  主题 997426game（前台门户）                     │
│   ├─ 首页：游戏网格 + 全站荣誉榜                 │
│   ├─ 归档：分类 / 搜索 / 标签                   │
│   └─ single-game.php：iframe 播放器 + 排行榜    │
│                                                 │
│  插件 997426-game-core（平台底座）               │
│   ├─ CPT: game + game_category + game_tag      │
│   ├─ 排行榜（自定义表 wp_game997426_scores）     │
│   ├─ 积分荣誉（wp_game997426_points_log）        │
│   └─ REST API: game997426/v1/*                  │
│                                                 │
│  游戏 SDK（game997426-sdk.js，所有游戏共用）      │
└─────────────────────────────────────────────────┘
          │ iframe 嵌入
          ▼
   静态 HTML5 游戏（/games/<slug>/index.html）
```

**核心设计原则**

- 每发布一篇 `game` 文章 = 上架一款小游戏；
- 游戏本体是与 WordPress 完全解耦的静态文件（零构建、可 CDN、加载快）；
- 所有游戏通过同一套 REST API 上报成绩 → 天然统一排行榜；
- 积分荣誉是全站级的（跨游戏累计），由插件自动结算。

## 2. 安装部署

### 环境要求

| 项目 | 要求 |
|---|---|
| WordPress | 6.x 及以上（含 7.1+） |
| PHP | 7.4+（推荐 8.x） |
| 数据库 | MySQL 5.7+ / MariaDB |
| HTTPS | 强烈建议（REST API + 登录态需要） |

### 步骤

1. **安装主题**
   把 `themes/997426game` 打包为 zip，后台「外观 → 主题 → 安装主题 → 上传」启用。
2. **安装插件**
   把 `plugins/997426-game-core` 打包为 zip，后台「插件 → 安装插件 → 上传」并激活。
   激活时自动创建数据表（排行榜 + 积分日志），无需手工建表。
3. **固定链接**
   后台「设置 → 固定链接」选择除"朴素"外的任意结构（如「文章名」），
   否则游戏归档页 `/game/` 无法访问。
4. **部署游戏目录**
   把整个 `games/` 目录复制到站点根目录（与 `wp-content` 同级），
   或任意可通过 HTTP 访问的静态目录 / CDN。
5. **菜单**
   后台「外观 → 菜单」创建主菜单（可加入「全部游戏」「排行榜」等页面）。

### 性能建议

- 游戏目录走 CDN 或开启浏览器缓存（静态资源天然适合缓存）；
- 缩略图使用 WordPress 生成的 `medium` 尺寸即可；
- PHP 启用 OPcache；数据库两张自建表均已建立复合索引。

## 3. 游戏上架流程（运营者）

> 前提：游戏文件已按第 4 节规范开发完毕，放入 `games/<你的游戏名>/index.html`。

1. 后台 → 「游戏」→「上架新游戏」（这就是普通文章编辑界面）；
2. 填写：
   - **标题**：游戏中文名；
   - **正文**：玩法介绍、操作说明（支持图文）；
   - **特色图片**：游戏封面（建议 800×600，会显示在首页卡片）；
   - **游戏分类 / 标签**：右侧栏勾选；
3. 在「自定义字段」中添加（若编辑器未显示，请在右上角「选项 → 偏好设置 → 自定义字段」打开开关）：

   | 字段名 | 必填 | 说明 | 示例 |
   |---|---|---|---|
   | `game997426_url` | ✅ | 游戏 index.html 的完整 URL | `https://example.com/games/snake/index.html` |
   | `game997426_width` | — | 设计宽度（默认 960） | `480` |
   | `game997426_height` | — | 设计高度（默认 640） | `480` |

4. 点「发布」。完成！前台自动出现卡片、播放器与排行榜。

> ⚠️ 注意：字段名以 `_` 开头属于隐藏字段，输入一次后保存即会记住。
> 若使用 ACF 等插件，可将上述 meta 映射为可视化字段。

## 4. 游戏开发规范（开发者）

### 4.1 技术形态

- **纯静态 HTML5**：单个 `index.html` 入口，配套 js/css/图片资源；
- 允许的技术：原生 Canvas/WebGL、DOM、以及任何**无后端**的前端库
  （Phaser、PixiJS、Kaplay 等，需随游戏自带或使用稳定 CDN）;
- **禁止**：服务端代码（PHP/Node）、独立数据库、独立域名跳转、
  自动跳转外链广告、挖矿脚本等一切恶意行为。

### 4.2 目录结构

```
games/
└── your-game/
    ├── index.html      ← 唯一入口（必需）
    ├── game.js         ← 游戏逻辑
    ├── style.css
    └── assets/
        ├── ...
```

- 游戏目录名 = 英文小写 slug（如 `snake`、`2048`），全站唯一；
- 入口必须叫 `index.html`，所有资源使用**相对路径**引用。

### 4.3 页面模板

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1, user-scalable=no, viewport-fit=cover">
<title>游戏名 · 997426</title>
<style>/* 内联或相对路径 */</style>
</head>
<body>
  <!-- 游戏内容 -->
  <script src="../../plugins/997426-game-core/assets/js/game997426-sdk.js"></script>
  <script src="game.js"></script>
</body>
</html>
```

> SDK 相对路径按游戏在 `games/` 下层级自行调整；
> 若游戏部署在与站点不同的域，请改为绝对 URL 并参考 §5.3 跨域说明。

### 4.4 视口与自适应（强制）

1. `<meta name="viewport">` 如上所示，必须包含 `user-scalable=no, viewport-fit=cover`；
2. 游戏画面必须**自适应容器尺寸**，推荐两种方式任选：
   - **Canvas 类**：监听 `resize`，按 `clientWidth/clientHeight × devicePixelRatio`
     重设画布物理像素，逻辑坐标保持不变（参见 snake 示例的 `resize()`）；
   - **DOM/CSS 类**：容器用 `min(96vw, 96vh - HUD高度)` + `aspect-ratio` 锁定比例，
     字号用 `clamp()` 缩放（参见 2048 示例）；
3. 禁止出现横向滚动条；禁止依赖固定窗口尺寸；
4. 支持横竖屏切换（切换时不得崩溃、状态不丢失）。

### 4.5 输入规范（强制）

| 设备 | 必须支持 |
|---|---|
| 电脑键盘 | 方向键 / WASD（至少其一），Enter/空格 开始或确认 |
| 手机触屏 | 滑动或点按操作；`touch-action:none` + `preventDefault` 防止页面滚动/双击缩放 |
| 通用 | 开始界面必须有明确的操作说明（同时写明键盘与触屏方式） |

### 4.6 行为红线

- ❌ 不得修改父页面 DOM / cookie / localStorage；
- ❌ 不得发起除本站 REST API 与自身静态资源以外的网络请求；
- ❌ 不得调用 `window.top.location`（禁止跳出 iframe）；
- ❌ 不得伪造分数上报（如循环调用 submitScore 刷分——服务端有防刷与人工审核）；
- ✅ 游戏结束才上报最终成绩；一局只报一次。

## 5. SDK 接入指南

### 5.1 快速接入（3 行代码）

```js
const sdk = await Game997426.ready(); // 初始化（幂等，可重复调用）

// 游戏结束时上报成绩：
const res = await sdk.submitScore(finalScore);
if (res.ok) {
  console.log('排名 #' + res.rank);            // 当前名次
  if (res.points_awarded) {
    console.log('获得积分 +' + res.points_awarded);
  }
}
```

### 5.2 其他接口

```js
// 当前玩家（未登录返回 {logged_in:false}）
const me = await sdk.getMe();
// => { logged_in:true, name:'张三', points:1234, badges:[{key,title,icon,time}] }

// 排行榜（limit 默认 10；period: all|day|week|month）
const lb = await sdk.getLeaderboard(10, 'all');
// => { rows:[{user_id,user_name,score}] }
```

### 5.3 运行环境判定

SDK 按以下顺序获取配置：

1. 同域 iframe / 直接访问：读取 `window.Game997426Config`（由宿主页注入）；
2. 跨域 iframe：向父窗口 postMessage 索要配置（自动降级，2s 超时）；
3. 都拿不到（本地 file:// 调试）：API 调用会静默失败，**游戏本体不受影响**。

因此开发时可完全脱离平台本地调试，无需 mock。

### 5.4 游戏 ID 从哪来？

宿主播放器会在 iframe 的 src 上附加 `?game_id=<文章ID>`，
SDK 自动解析。跨域场景下也可手动指定：

```html
<script>window.Game997426GameId = 42;</script>
```

## 6. 排行榜与积分荣誉规则

### 6.1 排行榜

- 单游戏榜：每用户取**历史最高分**排序（游客按单次成绩参与，不计入重复去重）；
- 时间维度：总榜 / 日榜 / 周榜 / 月榜（短代码与 API 均支持 `period` 参数）；
- 展示位置：游戏详情页侧栏自动展示；任何页面可用短代码：

```
[game_leaderboard game_id="42" limit="10" period="week"]
```

### 6.2 积分（💎 Points）

| 行为 | 积分 |
|---|---|
| 提交个人新纪录 | `floor(分数 ÷ 100)`，至少 +1 |

- 积分全站通用、跨游戏累计，余额存于 `user_meta`，流水存于积分日志表；
- 未登录玩家成绩照记（显示为“游客”），但不产生积分。

### 6.3 荣誉徽章

| 徽章 | 图标 | 达成条件 |
|---|---|---|
| 初出茅庐 | 🌱 | 第一次提交成绩 |
| 千分俱乐部 | 🎯 | 单局 ≥ 1000 分 |
| 万分传奇 | 👑 | 单局 ≥ 10000 分 |
| 登顶王者 | 🏆 | 任一游戏登顶第一 |
| 十项全能 | 🎮 | 玩过 10 款不同游戏 |
| 积分大亨 | 💎 | 累计积分 ≥ 5000 |

徽章在每次积分变动后自动结算；插件预留过滤器
`game997426_badge_definitions`，可注册新徽章而无需改核心代码。

### 6.4 防刷机制

- 成绩提交需携带 WordPress nonce（SDK 自动处理）；
- 服务端校验游戏存在性；分数取非负整数；
- 新纪录才发积分，同分重复提交不再发分；
- 建议运营者配合「WPCerber/iThemes」等安全插件限流 REST API。

## 7. REST API 参考

命名空间：`/wp-json/game997426/v1`

### POST /score — 提交成绩

```jsonc
// Request
{ "game_id": 42, "score": 1280, "nonce": "<来自 Game997426Config>", "extra": "" }

// Response 200
{ "ok": true, "best": 1280, "rank": 3, "points_awarded": 12, "total_points": 4520 }
```

错误：`403 invalid_nonce` / `404 invalid_game`

### GET /leaderboard?game_id=42&period=all&limit=10

```jsonc
{ "rows": [ { "user_id": "1", "user_name": "张三", "score": "99999" } ] }
```

### GET /me — 当前用户

```jsonc
{ "logged_in": true, "name": "张三", "points": 4520, "badges": [...] }
```

## 8. 质量验收清单

上架前逐项自查：

- [ ] `games/<slug>/index.html` 可直接在浏览器打开运行；
- [ ] 无控制台报错；
- [ ] Chrome（桌面）+ 微信内置浏览器 / Safari（iOS）实测通过；
- [ ] 键盘与触屏均能完整玩一局；
- [ ] 横竖屏 / 缩放窗口后布局正常；
- [ ] 游戏结束调用 `sdk.submitScore()` 且一局仅调用一次；
- [ ] 断网 / 未登录状态下游戏仍可正常游玩（成绩上报失败不影响体验）；
- [ ] 无外链、无广告、无恶意代码；
- [ ] 特色图片已设置，介绍文案含操作说明。
