# 997426 小游戏平台 · 游戏开发规范说明书（v2 插件架构）

> 版本 2.0 · 适用平台：WordPress + 「997426 游戏大厅」+ 游戏独立插件
>
> 本文档面向游戏开发者与运营者。v2 起，**每款游戏 = 一个独立的 WordPress 插件**，
> 上传启用即自动上架，无需 iframe、无需静态目录部署。

---

## 1. 平台架构（v2）

```
WordPress 站点
├── 主题 997426game          —— 门户外观（首页聚合排行 / 登录区）
├── 插件 997426 游戏大厅      —— 自动收集所有游戏，生成 /games-hub/ 大厅页
└── 每款游戏 = 独立插件       —— 如「997426 游戏-贪吃蛇」
    ├── 激活：建独立成绩表 + 自动创建并发布游戏页面 + 向大厅注册
    ├── 页面内直接渲染游戏（无 iframe）：登录态天然可用
    ├── REST: game-<slug>/v1（X-WP-Nonce 认证）
    └── 卸载：清理页面与数据表

首页全站积分排行：动态发现所有 wp_game997426_*_scores 表，
按「每人每游戏最高分 ÷ 100」求和聚合 TOP10——装新游戏自动纳入。
```

**为什么放弃 iframe（v1 教训）**：iframe 内调用 API 受 Cloudflare 缓存、
浏览器 Cookie 策略影响，登录态频繁丢失导致积分永远记为游客。
v2 中游戏运行在 WordPress 自己的页面里，这些问题从根源上消除。

## 2. 安装部署

| 组件 | 安装方式 |
|---|---|
| 主题 997426game | 外观 → 主题 → 上传 zip → 启用 |
| 游戏大厅插件 | 插件 → 安装插件 → 上传 `997426-game-hub-plugin.zip` → 启用 |
| 各款游戏 | 插件 → 上传对应 `997426-game-<slug>-plugin.zip` → 启用 |

启用游戏插件后**自动完成**：
1. 创建独立成绩数据表；
2. 创建并发布游戏页面（如 `/game-snake/`）；
3. 注册到游戏大厅（卡片自动出现）；
4. 纳入首页全站积分排行聚合。

后台会弹出成功提示并附页面直达链接。

**生命周期**：

| 操作 | 行为 |
|---|---|
| 停用游戏插件 | 页面进回收站（可恢复），从大厅消失 |
| 删除游戏插件 | 页面硬删 + 成绩表 DROP |

## 3. 开发一款新游戏的标准流程

1. 复制模板：`plugins-single/997426-game-snake/` → 改名 `997426-game-<slug>/`；
2. 全局替换标识符：函数前缀 `game_snake_*`、类名、表后缀 `_snake_scores`、
   REST 命名空间 `game-snake/v1`、短代码 `[game_snake]`、页面 slug；
3. 替换 `assets/game.js` 的玩法逻辑与 `assets/game.css` 的皮肤；
4. 按 §4 标准自查；打包上传启用即上架。

## 4. 强制开发标准

### 4.1 结构

```
997426-game-<slug>/
├── 997426-game-<slug>.php   ← 主文件（激活/停用/卸载钩子、REST、短代码、Metabox）
└── assets/
    ├── game.js              ← 玩法逻辑（body 最后一个脚本）
    ├── game.css             ← 皮肤
    └── sfx.js               ← 共享音效模块 GameSFX（直接复制，勿改接口）
```

### 4.2 必须包含的四要素 UI

| 要素 | 要求 |
|---|---|
| ① 开始游戏 | 首屏遮罩：名称+一句话玩法+双端操作提示+「▶开始」大按钮(≥48px) |
| ② 结束游戏 | HUD 常驻 ⏹ 按钮（游戏中显示，点击即结算上报）+ 自然失败结算；结算画面含得分/上报状态/🔄再来一局 |
| ③ 全屏按钮 | HUD 常驻 ⛶；`:fullscreen` 占满 100dvh+safe-area；舞台 `min(96vw,92vh-70px)` 方形居中（手机竖屏优先） |
| ④ 游戏介绍 | ❓ 弹窗：目标/规则/失败条件/双端操作/排行说明；打开时暂停 |

### 4.3 手机适配

- 虚拟方向键（贪吃蛇类）：仅触屏显示，JS 多信号检测
  （`ontouchstart`/`maxTouchPoints`/`pointer:coarse` 任一命中），
  **勿只依赖媒体查询**（部分手机浏览器不触发）；
- 触屏容器 `touch-action:none`，touchmove `preventDefault()`；
- 按钮 ≥44px 触控目标；canvas 监听 fullscreenchange/orientationchange 重算分辨率。

### 4.4 音效

引入共享 `sfx.js`（GameSFX，Web Audio 合成零文件）：
- 挂接 eat/move/click/over 事件；HUD 加 🔊 开关；
- 首次用户交互自动初始化 AudioContext；play() 需惰性创建 ctx（iOS 限制）。

### 4.5 数据与安全

- 成绩表结构固定：`user_id, user_name, ip_hash, score, created_at`；
- 游客记录加盐 IP 哈希（`md5(ip.wp_salt('auth'))`），排行榜按其去重；
- 提交接口必须 `X-WP-Nonce`（`wp_create_nonce('wp_rest')`）认证；
- 排行榜查询兼容 MySQL ONLY_FULL_GROUP_BY：**内层聚合去重、外层仅排序**；
  `$wpdb` 会静默吞 SQL 错误返回空——务必实测读取端；
- 榜单 transient 缓存 60s，并在标题旁注明「成绩约 1 分钟内同步」。

### 4.6 CSS 隔离（重要教训）

所有样式限定在游戏根类下（`.g2048-grid .tN`），裸类名 `.tile/.t2` 会被
主题全局样式覆盖导致颜色失效；关键配色加 `!important`。

### 4.7 大厅注册

激活钩子里调用（大厅未装时自动跳过，不报错）：

```php
if ( function_exists( 'game997426_hub_register' ) ) {
	game997426_hub_register(array(
		'slug' => $page_slug, 'title' => $title, 'url' => get_permalink($page_id),
		'icon' => '🎮', 'desc' => '一句话简介', 'plugin' => plugin_basename(__FILE__),
	));
}
```

停用时调用 `game997426_hub_unregister($slug)`。

### 4.8 行为红线

❌ 不修改父页面 DOM/localStorage　❌ 不发额外网络请求
❌ 不跳出页面　❌ 不伪造分数（一局只报一次，服务端限流）
