# 997426 游戏核心插件去留评估（2026-08-25）

## 背景
v2.0 起新架构：每款游戏 = 独立插件，游戏直接渲染在页面内。
旧「997426 游戏核心」插件的功能逐项评估如下。

## 功能清单与去留判断

| 旧功能 | 新架构下的状态 | 建议 |
|---|---|---|
| 游戏 CPT + 分类/标签 | ❌ 不再需要（游戏=插件，页面短代码上架） | 废弃 |
| iframe 播放器 single-game.php | ❌ 属于主题，新架构无 iframe | 废弃 |
| 统一排行榜 API | ⚠️ 被各游戏插件的独立榜取代 | 废弃 |
| 积分荣誉系统 | ❌ 用户已决定每游戏独立记录 | 废弃 |
| [games_grid] 卡片网格 | ❌ 依赖 game CPT | 废弃 |
| [game_leaderboard] / [user_points] | ❌ 各游戏自带榜单 | 废弃 |
| games/ 静态目录部署方式 | ❌ 新架构无静态目录 | 废弃 |

## 结论

**可以完全废弃。** 前提确认：
1. 你不再需要"全站统一排行榜/积分"——已确认（每游戏独立记录）
2. 已上架的游戏页面改用新短代码

## 附带清理项

- 主题 997426game 中依赖插件的部分（single-game.php、
  shortcodes 调用、Game997426Config 注入）将失效——但若你
  用普通页面+短代码上架，这些模板根本不会被触发，可不管；
  或换回任意默认主题亦可
- games/ 静态目录可从站点删除
- 数据表 wp_game997426_scores / wp_game997426_points_log 可删
