# 997426小游戏

基于 WordPress 的 HTML5 小游戏平台底座。

- **主题** `themes/997426game`：响应式游戏门户（首页/分类/单页播放器，自适应全屏，电脑键盘 + 手机触屏）
- **插件** `plugins/997426-game-core`：游戏 CPT、统一排行榜、全站积分荣誉系统、REST API
- **示例游戏** `games/`：贪吃蛇、2048（符合开发规范的可玩 demo）
- **文档** `docs/游戏开发规范说明书.md`：游戏接入标准与上架流程

## 快速开始

1. 安装主题与插件（zip 上传或复制到 `wp-content/`），激活插件（自动建表）；
2. 「设置 → 固定链接」选非朴素结构；
3. 将 `games/` 目录部署到站点根目录；
4. 后台「游戏 → 上架新游戏」，填自定义字段 `_game997426_url` 指向游戏 index.html，发布即上架。

详细说明见 [docs/游戏开发规范说明书.md](docs/游戏开发规范说明书.md)。
